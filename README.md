# student-management-system(python) 
A Python-based console application for managing student records using CRUD operations and JSON storage.

## Features
- Add student
- View students
- Update student
- Delete student
- Persistent storage using JSON

## Technologies
- Python
- JSON

## Concepts Used
- File handling
- CRUD operations
- Functions
- Lists and dictionaries

## Note
This is a console-based software development project (no HTML/CSS).
